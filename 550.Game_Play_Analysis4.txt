550. Game Play Analysis IV

Table: Activity

+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| player_id    | int     |
| device_id    | int     |
| event_date   | date    |
| games_played | int     |
+--------------+---------+
(player_id, event_date) is the primary key (combination of columns with unique values) of this table.
This table shows the activity of players of some games.
Each row is a record of a player who logged in and played a number of games (possibly 0) before logging out on someday using some device.

Write a solution to report the fraction of players that logged in again on the day after the day they first logged in, rounded to 2 decimal places. In other words, you need to determine the number of players who logged in on the day immediately following their initial login, and divide it by the number of total players.

The result format is in the following example.

 

Example 1:

Input: 
Activity table:
+-----------+-----------+------------+--------------+
| player_id | device_id | event_date | games_played |
+-----------+-----------+------------+--------------+
| 1         | 2         | 2016-03-01 | 5            |
| 1         | 2         | 2016-03-02 | 6            |
| 2         | 3         | 2017-06-25 | 1            |
| 3         | 1         | 2016-03-02 | 0            |
| 3         | 4         | 2018-07-03 | 5            |
+-----------+-----------+------------+--------------+
Output: 
+-----------+
| fraction  |
+-----------+
| 0.33      |
+-----------+
Explanation: 
Only the player with id 1 logged back in after the first day he had logged in so the answer is 1/3 = 0.33



SOLUTION:

SELECT 
  ROUND(
    COUNT(DISTINCT a.player_id) / COUNT(DISTINCT f.player_id),2
  ) AS fraction
FROM Activity a
RIGHT JOIN (
    SELECT player_id, MIN(event_date) AS first_login
    FROM Activity
    GROUP BY player_id
) f
ON a.player_id = f.player_id
AND a.event_date = DATE_ADD(f.first_login, INTERVAL 1 DAY);


EXPLAINATION:

🧩 Step 1: Understand the problem in simple words

We have a table called Activity, where each row tells us:

which player played,

on which date,

how many games they played that day.

We need to find:

The fraction of players who logged in again the day after their first login day.

📘 Example
player_id	event_date
1		2016-03-01
1		2016-03-02
2		2017-06-25
3		2016-03-02
3		2018-07-03

Player 1 → first login = 2016-03-01, next day login = 2016-03-02 ✅ (yes)

Player 2 → first login = 2017-06-25, no login next day ❌

Player 3 → first login = 2016-03-02, next day = 2016-03-03, but no login ❌

✅ So only 1 player out of 3 did that → 1 / 3 = 0.33

🧠 Step 2: What we need to do in SQL

We can solve this in 3 simple mini-steps.

🪜 Step A: Find each player’s first login date
SELECT player_id, MIN(event_date) AS first_login
FROM Activity
GROUP BY player_id;


This gives:

player_id	first_login
1		2016-03-01
2		2017-06-25
3		2016-03-02
🪜 Step B: Check if the player logged in the next day

We can join this result with the main Activity table to see if a record exists where event_date = first_login + 1 day.

SELECT a.player_id
FROM Activity a
JOIN (
    SELECT player_id, MIN(event_date) AS first_login
    FROM Activity
    GROUP BY player_id
) f
ON a.player_id = f.player_id
AND a.event_date = DATE_ADD(f.first_login, INTERVAL 1 DAY);


This will return only those players who did log in again the next day.

For the example:
→ Only player_id = 1 will appear.

🪜 Step C: Count how many did vs. total players

Now we can count:

numerator = number of players who returned the next day

denominator = total number of players

and divide.

SELECT 
  ROUND(
    COUNT(DISTINCT a.player_id) / COUNT(DISTINCT f.player_id),
    2
  ) AS fraction
FROM Activity a
RIGHT JOIN (
    SELECT player_id, MIN(event_date) AS first_login
    FROM Activity
    GROUP BY player_id
) f
ON a.player_id = f.player_id
AND a.event_date = DATE_ADD(f.first_login, INTERVAL 1 DAY);

✅ Final Correct Answer
SELECT 
  ROUND(
    COUNT(DISTINCT a.player_id) / COUNT(DISTINCT f.player_id),
    2
  ) AS fraction
FROM Activity a
RIGHT JOIN (
    SELECT player_id, MIN(event_date) AS first_login
    FROM Activity
    GROUP BY player_id
) f
ON a.player_id = f.player_id
AND a.event_date = DATE_ADD(f.first_login, INTERVAL 1 DAY);

🧾 How it works:
Step	What it does			Output
1️⃣		Find each player’s first login			(player_id, first_login)
2️⃣		Join back to check next-day logins		(players who returned next day)
3️⃣		Count returned / total				fraction like 0.33

💡 Tip:

DATE_ADD(f.first_login, INTERVAL 1 DAY) → adds 1 day to the date.

ROUND(..., 2) → rounds result to 2 decimal places.

We use RIGHT JOIN to make sure all players are counted, even if they didn’t return next day.
